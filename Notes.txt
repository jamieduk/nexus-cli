- Password-protected web UI via /web, /web off, /web reset, /web port <n>, /web status, with scrypt hashing, sessions, rate limiting, security headers, and a web Permissions panel.
- Agent directories are created and configurable in ai.json:
projects/, skills/, tools/, memory/, vault/, plus personality.md.
